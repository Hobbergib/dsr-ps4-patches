# Dark Souls Remastered (PS4) – GoldHEN patches

| Patch | Effect |
|---|---|
| Motion Blur Off | Removes camera motion blur |
| Depth of Field Off | Removes depth of field blur |
| Player Lantern Off | Removes the light around the player |

Tested on CUSA08495, version 01.03.

## Install

Copy `patches/xml/CUSA08495.xml` to `/data/GoldHEN/patches/xml/` on the PS4, turn on the patches in GoldHEN, and restart the game.

This file replaces any existing `CUSA08495.xml`. To keep other patches for this game, paste these `<Metadata>` blocks into your existing file instead.
